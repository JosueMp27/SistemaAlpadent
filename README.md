\# ALPADENT - Sistema de Gestión Odontológica



Sistema web para la gestión integral de una clínica odontológica.



\## Tecnologías



\- PHP

\- Laravel

\- MySQL/MariaDB

\- Laravel Sanctum

\- PHPUnit

\- JavaScript

\- Vite

\- Git



\## Principales módulos



\- Autenticación y usuarios

\- Gestión de pacientes

\- Gestión de citas

\- Diagnósticos y odontograma

\- Tratamientos

\- Pagos y abonos

\- Inventario y ventas

\- Doctores externos

\- Reportes

\- Configuración administrativa



\## Arquitectura



El sistema utiliza una arquitectura organizada por capas, separando controladores, servicios, repositorios, modelos y componentes de infraestructura.



\## Pruebas



El proyecto cuenta con pruebas automatizadas mediante PHPUnit, ejecutables mediante:



php artisan test
